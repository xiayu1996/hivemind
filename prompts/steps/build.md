# 步骤：构建一项

任务里写着这一项的目标和要做成的验收场景。

1. 读 `ARCHITECTURE.md`、`DESIGN.md` 里与这一项相关的部分，再看仓库里相关的代码；照已有的结构与约定加东西。
2. 逐条场景测试先行：写失败的测试，看它失败，写实现，看它通过。
3. 跑 `project.yaml` 的全部检查，直到全绿。
4. 有页面的，起一次产品，亲眼确认场景的页面到得了、`visible` 列的文字都在。
5. 调用 `submit_result`：`summary` 用中文写这一项现在让用户能做什么；`tests` 列出写过或改过的测试文件。

这不是第一次尝试时，工作区里已经是上一次的成果，任务里附着它被退回的原因：从那些原因入手修，不要推倒重来。
