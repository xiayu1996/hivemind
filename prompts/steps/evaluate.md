# 步骤：验收

任务里列着要判的场景。产品已经起好了，工具只能访问它。

对每条场景依次：
1. `begin_scenario`：开始这条场景（它需要的造数会在这时准备好）。之后的操作都记在这条场景名下。
2. `open_page` 打开场景的页面，按 `when` 用 `click`、`fill`、`press` 像人一样操作。元素按人叫它的方式指定：角色加可见名称。
3. 结果出现后，**在场景的页面上**调 `snapshot`，读返回的可访问性树，对照 `then` 与 `visible` 判断。
   需要看视觉效果时可以加 `screenshot`，但判定的依据是快照。
4. cli 场景用 `run_command` 运行场景的命令，依据是命令输出。

全部判完后调用 `submit_result`：每条场景一个结论，`evidence` 填工具返回的快照或输出 id。
结论不合格（引用了不存在的证据、快照里缺了 `visible` 的某一条、failed 没有引用契约原文）会原样退回，照提示改。

一条场景判不下来，就回去再看一次页面，别凭印象下结论：`passed` 只能来自你刚拍到的那份快照。
