# 可用性清单

这批条目判的是"人能不能用"，不是"好不好看"。每条都有编号，出口按编号回话：
不引编号的意见一律丢弃——没有编号的意见下一轮对不上，失败集合就永远不重复，判据也就永远不生效。

前四条（M）由代码判，判得出黑白，能打回重画。后三条（S）由判官逐条判，每条各问一次。

## M1 动效尊重 prefers-reduced-motion

页面里只要有 `transition` 或 `animation`，就必须有一段 `@media (prefers-reduced-motion: reduce)`
把它们关掉。前庭失调的人打开这一页不该被动画晃到。

## M2 触控目标不小于 44px

可点的东西（按钮、链接、表单控件）在手机宽度下的可点区域不小于 44×44px。
写死了更小的宽高、或用内边距凑不出这个尺寸的，算没过。

## M3 焦点可见

不允许出现没有替代的 `outline: none` / `outline: 0`：去掉了系统焦点环，就必须自己画一个
（`:focus-visible` 里给出 outline、box-shadow 或边框）。键盘用户看不见自己在哪一格，这一页就不能用。

## M4 键盘可操作

可点的东西必须是真的可聚焦元素：`button` / `a[href]` / 表单控件，或带 `role` 与 `tabindex` 的节点。
挂在 `div` / `span` 上的点击处理器，键盘走不到。

## S1 状态文案说清发生了什么、接下来做什么

空态、加载态、错误态、等待态的那句话，要让人知道现在是什么情况、自己该做什么。
"出错了"不算；"读不到任务，检查网络后重试"算。

## S2 校验提示可操作

表单校验的提示要说清怎么改对。"输入有误"不算；"手机号需要 11 位数字"算。

## S3 标签描述它旁边那个控件

每个输入控件的标签说的就是这个控件要填什么，不是它所在区块的标题，也不是一句泛泛的提示。
