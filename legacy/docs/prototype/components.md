# 访问状态

用于在设备不处于家庭或办公网络时阻止后台内容出现。页面只说明当前设备不能访问、需要连接哪个范围的网络以及如何重新检查，不展示运行数据或后台导航。

# 导航栏

用于在总览、费用、角色配置与工作记录之间切换，并提供返回当前运行态的稳定入口。当前页面有“当前”状态；手机端变为底部导航。详情与待办属于上下文页面，通过返回链接回到来源。

# 页面标题栏

说明当前页面解决的问题，并显示最近刷新时间或当前范围。可包含一个主要动作。刷新中状态不能让原有内容跳动。

# 基础控件

按钮直接写动作名称；次要按钮降低强调但仍保留清晰边界。输入框、搜索框和文本框在悬停、键盘定位、不可用和校验失败时都要有可辨认状态。下拉框使用统一的展开标记和右侧分隔，不显示浏览器默认箭头。单选与复选使用统一选择色，整行标签均可触达。所有控件的触控范围不小于 44 像素。

# 对话框

只用于保存配置、恢复上一版等需要本人再次确认且不能轻易撤销的操作。标题说明将发生什么，正文说明影响范围，底部提供明确动作和取消；对话框打开后不能让人误操作后方页面。

# 状态标签

用于“等待本人处理、运行中、失败、已完成、已超限”等互斥状态。颜色必须与文字同时出现，不能只靠色彩。费用超限不使用“已暂停”字样。

# 责任轨道

总览中专用于等待本人处理的事项。每行包含待办类型、所属需求、等待时长和明确动作。空状态邀请使用者检查运行项，不用占位卡片。

# 台账表格

用于费用、运行项和版本记录等需要横向比较的内容。数字右对齐。手机端每一行改为字段名与值配对的纵向记录；加载时显示具体正在读取的范围，错误时提供“重新读取”。

# 轮次切换器

用于在当前轮和历史轮之间切换。当前轮总是默认选中，每轮显示触发原因、阶段、结果、卡点和费用。历史轮只在使用者主动选择后展开。

# 费用指标

展示美元金额，并同时写明统计范围。可处于正常、接近上限和已超限状态。已超限状态必须说明工作仍继续。桌面端“每日费用”与“计费口径”组成同一比较组，上下边界对齐；手机端各自按内容自然高度排列。

# 待办表单

按待办类型呈现答复、批准或选择控件。每个控件有直接标签；校验提示说明如何改对。提交中禁用重复动作，成功后显示“已处理”以及结果已保留到对应 Notion 需求或任务。

# 版本对照

并排比较当前版与上一版的 Prompt、供应商和模型，差异用“新增、删除、变更”文字标识。桌面端两栏上下边界对齐，手机端按当前版、上一版的顺序自然排列。保存和恢复前均重申只影响之后新开始的智能体；已有智能体不变。

# 工作记录结果

左侧列出匹配记录，右侧显示完整记录和前后文。搜索词在正文中以非仅颜色的方式标出。空状态建议修改时间、角色或关键词；错误状态保留搜索条件并允许重试。

# 状态页

每页都具备空、加载、错误和等待四个完整状态。空状态说明当前没有什么并提供下一步；加载状态说明正在读取什么；错误状态说明无法读取的内容并提供重试；等待状态说明哪项结果尚未产生以及何时会自动刷新。
